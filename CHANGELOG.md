# Changelog

All notable changes to `3neti/x-rider` are documented here.

## [1.0.0] - 2026-07-31

- Establish the programmable claimant-experience and stage-driver contracts.
- Ship package-owned rider configuration, routes, default drivers, and Vue runtime.
- Enforce sanitized HTML, safe redirect, and normalized runtime-action boundaries.
- Support PHP 8.3 and 8.4 with Laravel 12 and 13.
- Add immutable PHP and frontend release verification.
